# Learning Haskell: A Functional Programming Journey 🚀

Welcome to my personal repository documenting my hands-on journey learning **Haskell** — a pure, statically typed functional programming language known for its elegant syntax, powerful type system, and mathematical rigor.

---

## 🧠 What This Is

This repository tracks my **practical Haskell learning progress**, including:
- Recursion practice
- List comprehensions
- Higher-order functions like `map`, `filter`, `foldr`
- Type classes and type annotations
- Pattern matching
- Helper function design
- Matrix operations and functional problem-solving

All code is written from scratch by me as I study and apply Haskell concepts through structured exercises.

---

| Week | Focus | What I Practiced |
